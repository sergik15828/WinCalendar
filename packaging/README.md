# Сборка установщика

Установщик предназначен для Windows 11 x64 и .NET Framework 4.8 или новее. Он устанавливает приложение для текущего пользователя без повышения прав.

Из корня проекта в Windows PowerShell:

```powershell
.\packaging\bootstrap-inno.ps1
.\build-installer.ps1 -Test
```

Bootstrap получает официальный Inno Setup 7.1.1 в `artifacts\tools\InnoSetup7`, проверяя закреплённый SHA-256 и Authenticode-подпись до запуска. Можно использовать свой компилятор: `build-installer.ps1 -Compiler "C:\Tools\Inno Setup 7\ISCC.exe" -Test`.

Результат: `dist\releases\WinCalendar-<версия>-Setup-x64.exe` и `SHA256SUMS.txt`. Версия берётся из собранного приложения. Для повторной упаковки без компиляции приложения предусмотрен `-SkipBuild`.

В пакет входят только приложение, конфигурация .NET, три командных файла и две инструкции. Пользовательский профиль, настройки, OAuth-данные, кэш и сборочные инструменты не включаются.

Проверка `-Test` запускает self-test приложения, затем компилирует отдельный вариант установщика с `InstallerSmokeTest`. В нём пути профиля и ярлыков перенаправлены в тестовый каталог, ключ автозапуска — в отдельную ветку HKCU, идентификатор удаления отличается от рабочего. Проверяются установка, обновление, включение/выключение автозапуска, ярлыки, удаление и сохранение синтетического профиля. Этот вариант не запускает и не останавливает рабочий WinCalendar и не публикуется в релизе.

Рабочий установщик закрывает WinCalendar только после подтверждения установки, обновляет файлы и запускает приложение через Проводник по выбору пользователя. Удаление убирает файлы, ярлыки и принадлежащий приложению автозапуск, сохраняя профиль и подключение Google. Системные мини-приложения Windows не переключаются автоматически.

Проверено для 0.8.1: 393 self-test проверки, 15 проверок установщика, а также установка рабочего пакета с регистрацией удаления и проверкой идентичности бинарника. Сборки пока не подписываются Authenticode.
