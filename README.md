# WinCalendar

День недели и число на значке панели задач Windows 11: например, **ЧТ / 12**. По клику открывается календарь; после подключения Google в нём видны дни со встречами и список выбранного дня. Дата и сетка месяца работают без интернета и учётных записей.

## Запуск и закрепление

Откройте `Start.cmd`. Скрипт `Install.ps1` копирует приложение в `%LOCALAPPDATA%\Programs\WinDate` и запускает его через Проводник Windows. Это важно: запуск через временный процесс PowerShell воспроизводил белый значок после завершения родителя. Рядом с `WinDate.exe` должен оставаться `WinDate.exe.config`.

Для постоянного значка без индикатора открытого приложения:

1. Нажмите правой кнопкой на значок даты → **Закрепить на панели задач**.
2. Приложение обнаружит закрепление и скроет собственную кнопку запущенного приложения. Останется закреплённый ярлык с обновляемой датой. Если закрепление происходит во время работы, обнаружение занимает до 30 секунд.
3. Перетащите значок первым среди приложений.
4. Если приложения по центру: **Параметры → Персонализация → Панель задач → Поведение панели задач → Выравнивание → Слева**.

Windows требует, чтобы закрепление выполнил пользователь. До закрепления приложение показывает обычную кнопку с нижним индикатором, чтобы значок не исчезал совсем.

## Календарь, меню и автозапуск

Нажмите на значок даты: рядом появится сетка месяца с понедельника. Стрелки переключают месяцы, кнопка **Сегодня** возвращает к текущей дате. Выбор дня в панели не меняет сегодняшнюю дату на значке. Кнопка **Открыть Google Calendar** открывает сайт в системном браузере.

Повторный клик по значку, Esc или клик вне панели закрывает её. С клавиатуры доступны стрелки для выбора дня, Page Up / Page Down для месяцев и Home для возврата к сегодняшней дате. Панель использует светлую или тёмную тему Windows и не создаёт собственной кнопки на панели задач.

Для меню **Запускать с Windows / Выйти** откройте `Settings.cmd` или **Пуск → WinCalendar → WinCalendar Settings**. Автозапуск включается по выбору пользователя; уже включённая настройка сохраняется при обновлении.

При входе в Windows календарь и браузер не открываются: запускается отдельный ярлык `Startup.lnk` с аргументом `--background` через `explorer.exe`.

Когда индикатор работает без закрепления, стандартная команда Windows **Закрыть окно** завершает работу. После закрепления выход доступен через `Settings.cmd`. Полный выход останавливает обновление даты на оставшемся ярлыке.

## Встречи Google Calendar

Однократная подготовка своего Google Cloud проекта и OAuth-клиента Desktop app описана в [GOOGLE_SETUP.md](GOOGLE_SETUP.md). Затем нажмите **Войти в Google**, введите данные клиента в окно приложения и разрешите чтение календаря в системном браузере. Для изменения клиента используйте **WinCalendar Settings → Настроить подключение Google**. Подключение Google в Codex не авторизует отдельное приложение Windows.

Если окно настройки уже открыто за другими окнами, повторный клик по дате или команде настройки возвращает его на передний план. Остаётся одно окно, введённые поля сохраняются; после закрытия или отмены настройку можно открыть снова.

- Читается основной календарь одного аккаунта. Дни со встречами отмечаются точкой; выбор дня показывает список под сеткой. Длинный список прокручивается. Клик или Enter открывает выбранное событие по ссылке Google Calendar.
- Повторяющиеся встречи раскрываются API в отдельные экземпляры. Учитываются отменённые экземпляры, события на весь день и многодневные события; время отображается в часовом поясе Windows.
- Панель показывает кеш сразу, затем обновляет данные при необходимости. Пока она открыта, проверка повторяется раз в две минуты. **Обновить** запускает ручное обновление. Загрузка не блокирует интерфейс; ответ предыдущего месяца не заменяет данные нового.
- При отсутствии сети сохраняются последние данные и время их обновления. Сообщения ошибки доступны полностью при наведении на обрезанный текст статуса. Состояние загрузки отличается от отсутствия встреч и необходимости повторного входа.
- OAuth использует PKCE и loopback `127.0.0.1`. Клиент и refresh token хранятся в Windows Credential Manager; access token — только в памяти. Кеш событий шифруется Windows DPAPI для текущего пользователя. Приложение запрашивает только `calendar.events.readonly`, встречи не изменяет.
- **Отключить** удаляет локальную сессию и кеш, затем отзывает доступ в Google. Без сети приложение сообщает, что удалён только локальный доступ. Данные OAuth-клиента сохраняются для повторного входа.

Режим Google OAuth **Testing** обычно требует повторного входа через 7 дней. Подробности и настройка Test users приведены в инструкции. Реальное подключение требует созданного вами клиента и согласия в браузере; автоматические тесты используют только синтетические события и учётные данные.

## Размер

Буквы дня недели и число заполняют доступную площадь значка с минимальными полями. Шрифты рисуются как контуры Segoe UI Bold и вписываются по фактической высоте букв, без внутренних шрифтовых отступов.

Размер самой кнопки задаёт Windows и не увеличивается отдельно для этого приложения. Если включены уменьшенные кнопки, в настройках панели задач можно выбрать **Показывать меньшие кнопки панели задач → Никогда**. Увеличение масштаба дисплея увеличивает весь интерфейс Windows. Приложение эти глобальные настройки не меняет.

## Обновление даты

Дата берётся из локального времени Windows, проверяется не реже чем раз в 30 секунд, отдельно планируется проверка на полночь. Поддержаны изменение системного времени и выход из сна. После временной ошибки записи значка повторяется попытка.

Текущая иконка — `%LOCALAPPDATA%\WinCalendar\WeekdayDate.ico`. В ней восемь 32-битных DIB-кадров: 16, 20, 24, 32, 40, 48, 64 и 128 пикселей. Ярлык меню «Пуск» — `WinCalendar\WinCalendar.lnk`. Собственные закреплённые ярлыки получают путь к актуальному ICO, Explorer уведомляется об изменении. Ручные AppUserModelID и свойства повторного запуска окна не используются.

В фоне остаётся нативный Windows Forms host. После закрепления у него нет собственной кнопки панели задач, поэтому он не должен создавать индикатор открытого приложения. При первом запуске без закрепления кнопка временно остаётся доступной для закрепления пользователем.

## Сборка и проверки

```powershell
.\Build.cmd
.\Build.cmd -Test
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -NoLaunch
```

Сборка использует встроенный в Windows .NET Framework 4.8, `csc.exe` и целевую платформу x64. Visual Studio, отдельный SDK, сторонние библиотеки и права администратора не нужны. Скрипт `Start.cmd` задаёт политику выполнения только для своего процесса PowerShell; постоянные настройки Windows не меняются.

Результат сборки — `dist\WinDate.exe`. Проверки записываются в `artifacts\self-test.txt`: проверяются размеры ICO, загрузка настоящим Windows Shell, невидимый автозапуск, скрытый host, сообщения повторного запуска, смена дня, года и високосный февраль. Отдельно проверяются сетка календаря, переключение месяцев, выбор даты, кнопки, размещение панели в рабочей области монитора и стиль окна без кнопки в панели задач. Обзор иконок — `artifacts\icon-sizes.png`; виды календаря — `artifacts\calendar-light.png` и `artifacts\calendar-dark.png`.

Проверки Google используют подменяемый HTTP-транспорт: PKCE, state, refresh, повтор после 401, страницы ответа, отказ доступа, отключение без сети, часовые пояса, исключительная граница окончания события, DPAPI-кеш и защита от запоздавших ответов. Настоящий loopback listener проверяется локальным синтетическим ответом браузера: неверный state отклоняется, правильный callback принимается, отмена освобождает порт. Windows Credential Manager проверяется отдельной временной синтетической записью, которая удаляется. Виды списка и состояний — `artifacts\google-events-*.png`; окно настройки — `artifacts\google-setup.png`. Проверяются масштабы 100%, 125%, 150%. Тесты не читают пользовательские встречи или установленную Google-сессию.

Отдельно требуется проверять фактическую смену значка уже закреплённого ярлыка после реальной полуночи. Синтетические тесты даты эту проверку не заменяют.

## Исходники

- `src\DateTaskbarWindow.cs` — фоновый Windows Forms host, таймер, меню.
- `src\CalendarPopup.cs` — всплывающая панель без кнопки в панели задач, размещение и закрытие.
- `src\CalendarPanel.cs` — сетка месяца, темы, кнопки и управление с клавиатуры.
- `src\CalendarState.cs` — сегодняшняя и выбранная даты, переходы между месяцами.
- `src\CalendarEvent.cs`, `CalendarEventList.cs` — модель события, отметки дней, список и ссылки.
- `src\GoogleCalendarClient.cs`, `GoogleOAuth.cs` — API, авторизация, обновление и отзыв сессии.
- `src\CredentialStore.cs` — собственные записи в Windows Credential Manager.
- `src\CalendarSync.cs`, `CalendarCache.cs` — асинхронное обновление, кеш DPAPI и состояния ошибок.
- `src\GoogleSetupDialog.cs` — ввод данных OAuth-клиента в приложении.
- `src\CalendarIcon.cs` — контуры букв, отрисовка и упаковка ICO.
- `src\DateText.cs` — русские сокращения дней недели.
- `src\ShellIntegration.cs` — ярлыки, обнаружение закрепления, обновление иконки, автозапуск.
- `src\Program.cs` — запуск, команды и единственный экземпляр.
- `src\SelfTest.cs` — нативные проверки.
- `Install.ps1` — обновление установленной копии и запуск через Проводник.

## Удаление

При подключённом Google сначала нажмите **Отключить** в календаре. Через `Settings.cmd` отключите автозапуск и выберите **Выйти**. Открепите значок. Удалите `%LOCALAPPDATA%\Programs\WinDate`, собственную папку `WinCalendar` в меню «Пуск» и, при желании, `%LOCALAPPDATA%\WinCalendar` с иконкой и кешем. Сохранённый OAuth-клиент можно удалить в Диспетчере учётных данных Windows: `WinCalendar/Google/DesktopClient`.
